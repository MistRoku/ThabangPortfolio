# Thabang Mokgonyana - Full-Stack Developer Portfolio

A responsive portfolio website built with **Angular 21 (standalone components)**, **SCSS**, **Lucide icons**, and **EmailJS** for the contact form.
It presents Thabang's projects, work experience, skills, contact information, Terms of Service, and Privacy Policy in a plain, professional layout.

The Angular application lives in the `ThabangPortfolio/` folder. See `ThabangPortfolio/README.md` for the full guide covering structure, features, setup, EmailJS configuration, deployment, and content editing.

## Quick start

```bash
cd ThabangPortfolio
npm install
ng serve
```

Production build:

```bash
ng build
```

## Design rules followed in this repo

Flat solid colors with a single accent, square corners, no drop shadows, no glass or blur panels, no gradients, no hover animations, Lucide icons with no emoji icons, a sideways scrolling project strip with skeleton loaders instead of a three-across card grid, and footer-linked Terms of Service and Privacy Policy pages.
